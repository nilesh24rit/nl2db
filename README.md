# nl2db

A multi-tenant SaaS platform for querying SQL and NoSQL databases using natural language.

## Problem it solves

Enables users to query databases using natural language instead of writing complex SQL or NoSQL queries. Reduces the need for deep database expertise for common data operations.

## Main capabilities

- Natural language to SQL/NoSQL query translation
- Multi-tenant data isolation and access control
- Support for relational and non-relational databases
- Intelligent query optimization
- Secure data access across tenant boundaries

## Supported database categories

- SQL databases (PostgreSQL, MySQL, MariaDB, etc.)
- NoSQL databases (MongoDB, Redis, Cassandra, etc.)
